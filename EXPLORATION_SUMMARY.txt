================================================================================
                            QUICK FINDINGS
================================================================================

1. FRAMEWORK: React 19.2.3 (Latest)
   - Modern hooks-based architecture
   - Create React App build system
   - No Redux or external state managers

2. STRUCTURE: Simple, Linear Flow
   - 5 main pages (components)
   - State-based routing (NOT React Router)
   - 2 API endpoints currently
   - ~914 total lines of code

3. STATE MANAGEMENT: React Hooks Only
   - Centralized in App.js
   - Props drilling pattern
   - No Context API (yet)
   - All state in useState hooks

4. API INTEGRATION: Axios + Minimal
   - Base URL from environment variables
   - Only 2 endpoints (check-user, signup)
   - No interceptors currently
   - Error handling via try-catch

5. AUTHENTICATION: NONE CURRENTLY
   - No token storage
   - No session persistence
   - No localStorage/sessionStorage usage
   - Telegram ID as pseudo-auth only

6. ROUTING: State Machine Pattern
   - 6 possible frame states
   - Switch statement in renderFrame()
   - No URL parameters
   - Cannot deep link or resume flow

================================================================================
                         ARCHITECTURE OVERVIEW
================================================================================

Current Data Flow:
  User Opens App
       ↓
  App.js mounts (useEffect)
       ↓
  Extract Telegram User ID
       ↓
  Call /api/onboarding/check-user
       ↓
  Determine new vs existing user
       ↓
  Show appropriate page (splash or redirect)
       ↓
  User fills form
       ↓
  Call /api/onboarding/signup
       ↓
  Redirect to platform


With Authentication:
  User Opens App
       ↓
  Check localStorage for token ← NEW
       ↓
  If token exists:
    - Send token with API requests ← NEW
    - Skip check-user if token valid ← NEW
  ↓
  If token invalid:
    - Clear and restart flow ← NEW
  ↓
  Form submission → Store token ← NEW
       ↓
  All future requests include token ← NEW

================================================================================

Base URL: https://hedg-bot-backend-zl7gphieia-el.a.run.app/api/onboarding

Endpoints:
  POST /check-user
    Input: { telegram_id: number }
    Output: { status: "new_user" | "existing_user", redirect_url? }
  
  POST /signup
    Input: { 
      first_name, last_name, email, phone_number, country,
      telegram_id, telegram_username, reward

    Output: { redirect_url, token? }
