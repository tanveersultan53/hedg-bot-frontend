                  AUTHENTICATION POINTS
                  ====================

    Current Flow (NO AUTH):
    ┌─────────────────────────────────────┐
    │ App Mount                           │
    │ ├─ Extract Telegram User ID         │
    │ ├─ Call /check-user                 │
    │ ├─ Determine new/existing           │
    │ └─ Show appropriate UI              │
    └─────────────────────────────────────┘
                    ↓
    ┌─────────────────────────────────────┐
    │ RewardForm Submit                   │
    │ ├─ Validate form                    │
    │ ├─ Call /signup                     │
    │ ├─ No token handling                │
    │ └─ Redirect to platform             │
    └─────────────────────────────────────┘


    After Auth Implementation:
    ┌─────────────────────────────────────┐
    │ App Mount                           │
    │ ├─ Check localStorage for token     │
    │ ├─ If exists, validate token        │
    │ ├─ If valid, skip check-user        │
    │ └─ If invalid, start fresh flow    │
    └─────────────────────────────────────┘
                    ↓
    ┌─────────────────────────────────────┐
    │ API Requests                        │
    │ ├─ Add auth token to headers        │
    │ ├─ axios.interceptors.request       │
    │ │  └─ Authorization: Bearer {token} │
    │ └─ axios.interceptors.response      │
    │    ├─ Store token if in response    │
    │    └─ Handle token refresh          │
    └─────────────────────────────────────┘
                    ↓
    ┌─────────────────────────────────────┐
    │ Logout (Future)                     │
    │ ├─ Clear localStorage token         │
    │ ├─ Clear API headers                │
    │ └─ Redirect to login                │
    └─────────────────────────────────────┘
